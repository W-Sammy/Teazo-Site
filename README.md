# TEAZO — Bubble Tea Business Platform

## Overview

**TEAZO** is a modern web platform designed for a small bubble tea business to improve branding, customer engagement, and business operations through a centralized digital experience.

Built as a senior project at California State University, Sacramento, the platform provides a fully customizable storefront experience with menu management, authentication, responsive UI design, and business-side administration tools.

The project focuses on delivering:
- A scalable and modern web architecture
- Mobile-friendly customer experience
- Administrative content management
- Third-party integrations for authentication and payment systems

---

# Project Synopsis

Many small businesses rely heavily on third-party delivery apps and templated storefront services that limit branding flexibility, customer communication, and customization.

TEAZO addresses this issue by providing a dedicated, customizable business website that allows the owner to:
- Control branding and customer experience
- Manage menu content dynamically
- Improve visibility and online engagement
- Build a scalable foundation for future growth

The system is developed using modern full-stack web technologies with a focus on maintainability, responsive design, and cloud deployment.

# Installation

## Prerequisites

Install:
- Node.js (v18+ recommended)
- npm
- Git

---

## Clone Repository

```bash
git clone https://github.com/W-Sammy/Teazo-Site.git
cd Teazo-Site
```

---

## Install Dependencies

```bash
npm install
```

---

## Run Development Server

```bash
npm run dev
```

Application will run at:

```bash
http://localhost:3000
```
